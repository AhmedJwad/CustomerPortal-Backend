## 📖 Overview

CustomerPortal Backend is the server-side engine of a customer portal platform. It provides secure authentication, role-based access, and reliable data management, giving administrators a single place to manage users, products, orders and customers.

## ✨ Key Features

- 🔐 **Secure Authentication** — Token-based login with protected endpoints
- 👥 **User & Role Management** — Fine-grained access control for every user
- 🚦 **Account Status Control** — Activate, suspend or restrict accounts instantly
- 🔑 **Password Recovery** — Self-service reset via email
- 🛡️ **Strong Security Policies** — Enforced password rules and request protection
- 🌐 **Frontend Ready** — Fully integrated with the React admin dashboard
